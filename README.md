# Dalty Science

تطبيق علوم تفاعلي للصف الثاني الإعدادي، يرافق شرح الأستاذ إيهاب مازي على قناة **Discover with Dalty**.
يبدأ بالوحدة الأولى (المادة والطاقة)، وباقي وحدات المنهج تُضاف تباعًا.

> Interactive science app for Grade 8, starting with Unit 1 (Matter & Energy), with particle simulations, virtual labs, quizzes, and an offline AI assistant. More units are being added.

## المتاح حاليًا

**الوحدة الأولى: المادة والطاقة**

1. حالات المادة
2. تغيّر حالات المادة
3. الطاقة الداخلية ودرجة الحرارة
4. طرق انتقال الحرارة

## ما يقدمه كل درس

- فيديو شرح وانفوجراف مبسّط
- محاكاة حيّة للجسيمات وتجارب تفاعلية
- أنشطة مطابقة وتصنيف
- بطاقات "علّل" مع تصحيح إجاباتك بالمساعد الذكي
- أسئلة اختبار وأسئلة من كراسة الأداءات والتقييمات
- معلومات إثرائية خارج المنهج

## مميزات عامة

- مساعد ذكي يعمل بدون إنترنت
- حفظ تقدّم الطالب تلقائيًا على جهازه (`localStorage`)
- يعمل على الهاتف والكمبيوتر

## قريبًا

باقي وحدات المنهج.

## التشغيل

التطبيق ملف واحد (`index.html`) بلا أي تثبيت. افتحه مباشرة في المتصفح، أو انشره عبر GitHub Pages:

1. `Settings` ← `Pages`
2. `Source`: **Deploy from a branch**
3. الفرع `main` والمجلد `/ (root)` ثم `Save`
4. الرابط: `https://USERNAME.github.io/dalty-science/`

## هيكل المستودع
